📦 What Is An Array? (Deep Beginner Version)

Array =

👉 A collection of values stored under ONE name.

Example:

int[] arr = {10, 20, 30};


This creates 3 boxes:

Index 0 → 10
Index 1 → 20
Index 2 → 30

Important:
Index starts from 0.

🧠 Visual Model

Think of it like:

Index	Value
0	10
1	20
2	30

So:

arr[0] = 10
arr[1] = 20
arr[2] = 30
